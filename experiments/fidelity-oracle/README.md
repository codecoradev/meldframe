# Fidelity oracle (experiment for docs/fidelity-contract.md)

Compares what the HTML/Tailwind export produces in Chromium with what the layout core computes (the rects the canvas draws).
It is an experiment harness, not product code. It reads the spike repo read-only and never modifies it.

## Prerequisites

- Spike checkout (default `/home/user/wonder-proto`, branch `spike/rust-core`, commit `ca74052`; override with `SPIKE_DIR`) with `node_modules` (pixi.js 8.23.0, tailwindcss 4.3.5) and `tools/capture/assets/inter.woff2` (override with `FONT_PATH`).
- Playwright installed globally (`/opt/node-tools/node_modules/playwright`, Chromium 153), Node 22.
- The spike export CLI, built into a private target dir:

```bash
cd $SPIKE_DIR
CARGO_TARGET_DIR=/home/user/meldframe-wt/target-b1 cargo build --release --offline --locked -p spike-export --bin spike-export
```

## Run

```bash
cd experiments/fidelity-oracle
export CARGO_TARGET_DIR=/home/user/meldframe-wt/target-b1
node run.mjs                       # A: boxes, as exported by the spike (oracle-A.json)
node run.mjs --safe --ws           # A: with candidate CSS fixes (oracle-A.safe.ws.json)
node run.mjs --fuzz                # A: 200 seeded random documents, raw   (FUZZ_N=200)
node run.mjs --fuzz --norm         #    + rule N1 (fill under hug becomes fixed)
node run.mjs --fuzz --norm --safe --ws
node analyze-fuzz.mjs              # split fuzz docs into fit-in-container vs overflow/degenerate
node classify-residual.mjs fuzz.norm.safe.ws
node pixel.mjs                     # B: border / shadow / image probes on the overlay pages
node text-ink.mjs                  # C: Pixi text (as Canvas.svelte draws it) vs DOM text, ink bounding boxes
node shadow-pixi.mjs               # D: Pixi BlurFilter vs CSS box-shadow falloff
node bench.mjs                     # speed: Rust CLI vs DOM relayout (rough wall-clock)
node gate.mjs                      # CI gate, exit 1 on violation
```

`out/` (HTML, screenshots, large JSON) is git-ignored. `results/` holds the committed summary numbers (small files); the per-node oracle A output (`results/oracle-A*.json`, about 110 KB each) is regenerated by `run.mjs` and is git-ignored.

## Files

| File | Role |
|---|---|
| `fixtures.mjs` | 11 hand-written fixtures + seeded fuzz generator (`fuzz(seed)`) |
| `lib.mjs` | static server, Chromium, measurement page (Pixi `CanvasTextMetrics` + Inter, weight aware, records the text table) |
| `run.mjs` | oracle A: core rects (TS oracle `src/lib/layout.js`) vs Rust core vs DOM rects, HTML and Tailwind, 3 viewport/DPR combinations |
| `overlay.mjs` | candidate mapping for properties the spike export does not emit (border, shadow, image, weight, align) |
| `normalize.mjs` | candidate rule N1 |
| `pixel.mjs`, `text-ink.mjs`, `shadow-pixi.mjs` | oracles B, C, D |
| `bench.mjs`, `gate.mjs`, `analyze-fuzz.mjs`, `classify-residual.mjs` | speed, CI gate, fuzz analysis |
